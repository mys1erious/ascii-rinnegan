# ASCII Rinnegan

The Rinnegan as ASCII: it wakes up, looks around and blinks. Move your cursor and it follows you; hold and let go for
shinra tensei. Every frame is monospace text. One HTML file, no dependencies.

**Live:** https://mys1erious.github.io/ascii-rinnegan/

On a phone, drag to make it look around.
